Menu Ompreng SPPG Masuk Admin

Satu scan, langsung tahu isi omprengnya

Setiap ompreng ditempeli satu stiker berisi QR. Saat di-scan pakai kamera HP, yang muncul hanya gambar menu hari itu — lengkap dengan rincian komponen, kandungan gizi, berat porsi, dan asal dapurnya.

Bagaimana cara kerjanya?

1

Stiker dicetak sekali

Stiker QR ditempel di ompreng. Kodenya permanen, tidak perlu diganti setiap hari.

2

Admin isi menu harian

Setiap hari admin memasukkan komponen menu, gizi makro, dan foto masakan.

3

Gambar dibuat otomatis

Sistem menyusun poster menu sebagai file gambar dan menaruhnya di alamat tetap.

4

Scan → muncul gambar

QR menunjuk langsung ke file gambarnya, jadi di HP hanya tampil posternya saja.
